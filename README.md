# Итоговые работы по алгоритмам

Четыре программы к итоговым заданиям курса. Python 3.9 и выше, внешних библиотек нет.

## Динамическое программирование

`dp_tasks.py` решает пять задач из задания: последовательности без двух единиц подряд,
число путей по полю, минимальный маршрут с диагональю, наибольшая возрастающая
подпоследовательность и наибольший палиндром вычёркиванием букв.

```
python3 dp_tasks.py
```

Печатает ответы по всем пяти задачам. В конце файла короткие пояснения к переходам
и сложности.

## Диспетчер заявок

`tickets_tree.py` держит заявки в бинарном дереве поиска по номеру, строит максимальную кучу
по приоритету и сортирует кучей для отчёта. Внутри вставка, поиск и удаление в трёх случаях,
четыре обхода, высота, листья, проверка свойства дерева диапазонами.

```
python3 tickets_tree.py
```

## Маршруты кампуса

`campus_graph.py` строит граф из восьми объектов и двенадцати маршрутов, считает степени
и плотность, обходит в ширину и глубину, ищет кратчайшие пути алгоритмом Дейкстры и
Флойда-Уоршелла, восстанавливает маршрут и считает диаметр, радиус и центр.

```
python3 campus_graph.py
```

Центр графа получается столовая, это и есть ответ на вопрос, где ставить пункт помощи.

## Реестр оборудования

`hash_registry.py` хранит двадцать позиций в хеш-таблице четырьмя способами: цепочки,
линейное пробирование, квадратичное пробирование, двойное хеширование. Считает коллизии,
среднее число проб и длину кластера, перестраивает таблицу при заполнении выше 0.7.

```
python3 hash_registry.py
```

Коллизий во всех вариантах семь, а проб больше всего у линейного пробирования и меньше
всего у двойного хеширования.
